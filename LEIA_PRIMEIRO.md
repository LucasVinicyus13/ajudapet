# 🎯 COMECE AQUI - Erro de Denúncia

## O Problema
Você está vendo este erro:
```
❌ Não foi possível registrar a denúncia. Tente novamente.
```

## A Solução (3 minutos)
As **regras de segurança do Firestore** precisam ser publicadas.

### Opção 1: Guia Visual (Recomendado) ⭐
👉 **[Abra: configurar.html](./configurar.html)**

Você verá um passo a passo com checkboxes. Muito fácil!

### Opção 2: Instruções Rápidas
1. Vá para: https://console.firebase.google.com
2. Projeto: `ajudapet-2d3c6`
3. Menu: **Firestore Database** → **Regras**
4. Copie o código de [SOLUCAO_RAPIDA.md](./SOLUCAO_RAPIDA.md)
5. Cole no Firebase Console
6. Clique **PUBLICAR** (não é rascunho!)
7. Aguarde 30 segundos
8. Recarregue o site

### Opção 3: Verificar o Erro
👉 **[Abra: teste-denuncia.html](./teste-denuncia.html)**

Mostra exatamente qual é o erro.

---

## ✅ Como Saber que Funcionou
- ✅ Nenhuma mensagem de erro
- ✅ "Denúncia registrada com sucesso!" aparece
- ✅ O cliente de e-mail abre automaticamente
